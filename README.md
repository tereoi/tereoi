### About

Good code is readable, fast and secure. That's what I focus on across the whole stack. I like optimizing things, keeping them simple and making sure they scale without turning into a mess. A feature that works is a start, a feature that's fast, maintainable and easy to extend is the goal.

I work with AWS Bedrock and think AI is interesting when it's done right. That means thinking about security, keeping it predictable and making sure it adds something real rather than just being there.

### 🖥️ Frontend

The part of an application users see and interact with.

<div>
  <img src="https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white" />
  <img src="https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB" />
  <img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" />
  <img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black" />
</div>

<br/>

**Next.js** is the main framework I use for building web apps. It sits on top of React and handles routing, server-side rendering and performance out of the box so you can focus on building instead of configuring.

**React** is the underlying library for building interfaces out of components. It keeps the UI predictable and easy to reason about as an application grows.

**TypeScript** is JavaScript with types. It catches mistakes before they reach production and makes large codebases much easier to work with.

**JavaScript** is the language the web runs on. TypeScript compiles to it, but knowing JS well still matters.

### ⚙️ Backend

The server-side of an application. Handles logic, data processing and communication between the frontend and the database.

<div>
  <img src="https://img.shields.io/badge/NestJS-E0234E?style=flat-square&logo=nestjs&logoColor=white" />
  <img src="https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white" />
  <img src="https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white" />
</div>

<br/>

**NestJS** is the framework I use for building backend APIs. It enforces a clear structure and works natively with TypeScript, which keeps large backends organized and consistent.

**Node.js** is the runtime that lets you run JavaScript on the server. NestJS and most modern backend tools in the JavaScript ecosystem run on top of it.

**PostgreSQL** is a relational database. It stores the data and handles queries. I use it for most projects where data structure and reliability matter.

### ☁️ Cloud AWS

Infrastructure for deploying and running applications at scale, without managing physical servers

<div>
  <img src="https://img.shields.io/badge/AWS_Lambda-FF9900?style=flat-square&logo=awslambda&logoColor=white" />
  <img src="https://img.shields.io/badge/Amazon_S3-569A31?style=flat-square&logo=amazons3&logoColor=white" />
  <img src="https://img.shields.io/badge/Amazon_Bedrock-232F3E?style=flat-square&logo=amazonaws&logoColor=FF9900" />
</div>

<br/>

**Lambda** is a serverless compute service. You write a function, deploy it, and AWS runs it when needed. No server setup, no maintenance, scales automatically with traffic.

**S3** is cloud object storage for files, images, exports and backups. Reliable and easy to connect to other AWS services.

**Bedrock** is AWS's managed service for working with large language models like Claude. I use it to build AI features into applications that are actually useful rather than just there for show.
